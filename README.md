# MAGNUM IMMOBILIÈRE - Premium Real Estate Showcase

Une vitrine digitale conçue pour un promoteur immobilier d'élite, respectant les lignes directrices des distinctions Awwwards.

## 🛠️ Déploiement Ultra Rapide
1. Créez un dépôt sur votre compte GitHub.
2. Ajoutez les fichiers `index.html`, `style.css`, et `script.js` à la racine.
3. Liez le projet à **Cloudflare Pages** (ou GitHub Pages).
4. La plateforme de luxe est instantanément opérationnelle en ligne.
